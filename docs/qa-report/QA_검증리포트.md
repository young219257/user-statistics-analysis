# 이용자통계분석 QA 검증 리포트

- 대상: `https://testlab-edmgr.kr/apps/app-20261006-160341/` (검증일 2026-11-09)
- 방법: 앱이 쓰는 REST API(`/api/v1/*`)를 익명 세션으로 직접 호출하고, 같은 데이터를 Python(pandas 3.x, scipy, statsmodels 0.15, scikit-learn, pingouin 설치)으로 독립 계산해 대조했습니다.
- **검증 방식 2단계**: (1) API 직접 호출 + Python 재계산(2~7절), (2) 시스템 Chrome을 Playwright로 조작한 **실제 화면 검증**(8절, 캡처는 `screenshots/`). 화면 검증은 STEP1~5 한 바퀴를 돌렸지만 **기법은 선형회귀(실행만)와 다층모형(HLM)만 화면에서 확인**했습니다. 나머지 기법의 화면·PDF·Excel은 확인하지 못했습니다(5절, 8절 참고).
- **정정(2026-11-11)**: 초기 리포트는 XLSX 반입 실패의 원인을 "다중 시트"로 적었으나, 재검증 결과 **한 열에 숫자와 문자가 섞인 데이터** 때문이었습니다(시트 1개 파일도 동일하게 실패, 시트 2개여도 데이터가 깨끗하면 성공). D-03(다중 시트는 첫 시트만 반입)과 D-24(혼합 열 실패)로 나누어 정리했습니다.
- 수치 대조: 98개 값 비교, **불일치 0건** (`data/compare.json`).

## 1. 요약

| 영역 | 판정 | 한 줄 요약 |
|---|---|---|
| 문제점 분석(진단·경고·해석) | **실패** | 통계 가정 위반·데이터 문제를 문구로 알려 주지 않습니다. 서버 `warnings`는 시험한 거의 모든 위반 상황에서 빈 배열이었습니다. |

### 핵심 결함 상위 5개

1. **D-01 (치명)** 마할라노비스 거리가 거리(D)가 아니라 **제곱거리(D²)**를 임계값과 비교합니다. 기본 임계값 3.0에서 388행 전체(100%)가 이상치로 표시됩니다(정답 148행).
2. **D-02 (높음)** 가정 위반 경고가 사실상 없습니다. VIF 10,061, DW 0.25, 완전분리, 클래스 불균형 3%, n=8, 매칭률 0%, 다층모형 미수렴에서도 `warnings`가 비어 있습니다.
3. **D-24 (높음)** 한 열에 숫자와 문자가 섞인 XLSX(예: 쉼표 숫자 `"6,865"` + 숫자)를 올리면 서버가 `internal_error`로 실패합니다. 같은 데이터를 CSV로 올리면 정상입니다. (처음에는 다중 시트가 원인으로 보고했으나, 단일 시트 파일도 실패해 **정정**했습니다.)
4. **D-04 (높음)** 앞자리 0이 있는 학교코드(`"00101"`)가 숫자 `101`로 읽혀 코드가 바뀝니다. 경고가 없습니다.
5. **D-05 (높음)** K-평균·PCA가 표준화 없이 원척도로 계산합니다(`preprocessing_steps`가 빈 배열, 옵션 없음). 스케일이 큰 변수가 결과를 지배합니다.

- 해석 문구(p값·인과·비유의 결과 표현)는 `interpretation`이 상관분석의 "|r| ≥ 0.7인 강한 상관 쌍이 1개 있습니다."만 확인했고, 다른 기법의 해석 문구와 화면 문구는 **확인하지 못했습니다**.
- 조건을 바꿔 재분석했을 때 진단이 바뀌는지는 위 실험에서 데이터별로 다른 결과가 나오는 것으로만 간접 확인했습니다(UI 재분석 흐름은 미확인).

## 5. 확인하지 못한 항목과 이유

- **화면 캡처 전체**: 브라우저 조작 도구가 없어 화면을 볼 수 없었습니다. 따라서 화면에 표시되는 문구, 차트, 레이아웃은 판정하지 못했습니다.
- **PDF/Excel 출력과 화면 값의 일치(STEP5)**: 파일 생성 흐름(`/api/v1/packages`)을 호출하지 않았습니다.
- **해석 문구 전반**: 상관분석의 `interpretation` 한 건만 읽었고, p값·효과크기·인과 표현은 화면 기준으로 점검하지 못했습니다.
- **수치를 대조하지 못한 기법**: 의사결정나무(분할·무작위성), 계층적 군집, DBSCAN, 성장곡선, PSM의 매칭 결과·ATT(구현·무작위 시드에 따라 재현 불가). 성장곡선은 입력 구조상(wide 형식) 의미 있는 대조 데이터를 만들지 못했습니다.
- **로지스틱의 오즈비·CI·z값**: 계수·AIC·McFadden·로그우도만 대조했습니다.
- **Isolation Forest, LOF 이상치 개수**: 무작위/알고리즘 의존이라 정답 대조하지 않았습니다(결과: 각각 65, 18).
- **CP949 CSV**: UTF-8과 열 이름·고유값·결측 수가 동일함까지 확인했고, 값 단위 비교는 하지 않았습니다.
- **날짜 열**: `survey_date`가 `datetime`으로 추론됨만 확인했습니다.
- **키만 같은 중복 3행(student_id 중복)**: 프로파일의 `n_duplicated_rows=5`는 완전 중복만 센 값으로 보이며, 키 중복을 별도로 알리는 기능은 찾지 못했습니다.
- **STEP5 재분석 시 규칙 재적용, 리포트에 적용 규칙 기록**: UI 흐름이라 확인하지 못했습니다.
- **서버 로그**: 혼합 타입 열 XLSX가 `internal_error`로 끝나는 내부 원인(타입 추론 오류로 추정)은 서버 로그에 접근할 수 없어 확인하지 못했습니다. 재현 조건(숫자+문자 혼합 열)까지 좁혔습니다.

## 6. 검증 중 확인한 사실과 주의

- **D-23은 제가 앞서 수정한 코드의 부작용입니다.** 이전에 캐시 문제를 막으려고 JSP의 JS/CSS 주소에 `?v=<%= System.currentTimeMillis() %>`를 붙였는데, 테스트랩은 JSP를 서버에서 실행하지 않고 정적 파일로 서빙해서 이 문자열이 그대로 URL에 들어갑니다. 정적 서버가 쿼리를 무시해서 파일은 로드되지만, 의도한 캐시 방지는 동작하지 않습니다. 정적 호스팅에서도 동작하는 방식(빌드 번호 등)으로 바꾸는 편이 좋습니다.
- **검증 중 대상 서비스에 데이터를 올렸습니다.** 익명 세션으로 약 40건의 데이터셋과 분석을 생성했고, 안내된 대로 마지막 사용 1시간 후 삭제됩니다.
- 수치 대조는 문제를 주입하지 않은 `qa_clean_reference.csv`로 했습니다. 알고리즘 정확성과 데이터 문제 처리를 분리하기 위해서입니다.
