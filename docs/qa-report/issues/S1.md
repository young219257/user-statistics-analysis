마할라노비스 거리 탐지의 기본 임계값 3.0에서 전체 행(388/388, 100%)이 이상치로 판정됩니다. 화면에서도 모든 변수가 100.00% / "검토 필요"로 표시됩니다.

## 원인 (서버 소스 확인)
