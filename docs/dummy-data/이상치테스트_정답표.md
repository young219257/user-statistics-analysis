# 이상치 탐지 화면 테스트용 더미 데이터

| 파일 | 설명 |
|---|---|
| `이상치테스트_더미데이터.xlsx` | 시트 1개(`data`), 300행 × 9열. 1단계에서 이 파일을 올리면 됩니다. |
| `이상치테스트_더미데이터.csv` | 같은 내용의 CSV (UTF-8 BOM). 엑셀 대신 CSV로 시험할 때 사용. |

## 열 구성

| 열 | 내용 | 화면에서의 취급 |
|---|---|---|
| `student_id` | S0001~S0300 (문자) | 식별자 → 진단 대상 아님 |
| `score_math`, `score_eng`, `score_sci` | 서로 상관이 높은(0.7 안팎) 점수 | 진단 대상 |
| `study_hours` | 오른쪽으로 치우친 값 | 진단 대상 |
| `income` | 오른쪽으로 치우친 값 | 진단 대상 |
| `satisfaction` | 1~5 척도(이산형) | 진단 대상 (IF·LOF에서 불안정 안내가 뜸) |
| `grade` | 1~3 (이산형) | 진단 대상 |
| `passed` | 0/1 | 이진 → 진단 대상 아님 |

화면의 진단 대상은 **7개 변수**입니다 (`student_id`, `passed` 제외).

## 심어 둔 이상치 (엑셀 행 번호 기준, 1행은 머리글)

| 엑셀 행 | 심은 값 | 성격 |
|---|---|---|
| 11 | score_math = 130 | 단변량: 점수 한 개가 크게 벗어남 |
| 26 | score_math = 5 | 단변량: 아래쪽으로 벗어남 |
| 51 | study_hours = 38 | 단변량: 공부시간 극단값 |
| 76 | income = 42,833 (중앙값의 약 14배) | 단변량: 소득 극단값 |
| 101 | score_eng = 135 | 단변량 |
| 151 | 수학 94 / 영어 42 / 과학 50 | **조합 이상**: 변수 하나씩은 정상 범위인데 조합이 이상 |
| 201 | 수학 45 / 영어 98 / 과학 92 | **조합 이상** |
| 251 | 수학 96 / 영어 45 / 과학 95 | **조합 이상** |

> 화면의 표본 목록에 나오는 `#N행`은 **0부터 센 번호**입니다. 엑셀 행 = N + 2 입니다. (예: `#9행` → 엑셀 11행)

## 기법별 기대 결과 (변수별 이상치 건수)

IQR·Z-score·수정 Z·Grubbs는 **화면 결과와 서버 코드 재현 결과가 일치함을 확인**했습니다.

| 기법 | score_math | score_eng | score_sci | study_hours | income | satisfaction | grade |
|---|---|---|---|---|---|---|---|
| IQR 1.5배 | 5 | 3 | 2 | 17 | 7 | 21 | 0 |
| Z-score 3.0 | 2 | 2 | 0 | 1 | 1 | 0 | 0 |
| 수정 Z 3.5 | 2 | 1 | 0 | 6 | 7 | 0 | 0 |
| Grubbs α=0.05 | 2 | 1 | 0 | 3 | 2 | 0 | 0 |
| Isolation Forest 0.55 | 22 | 22 | 28 | 21 | 14 | 68 | 0 |
| Isolation Forest 0.60 | 9 | 10 | 17 | 12 | 10 | 21 | 0 |
| Isolation Forest 0.65 | 5 | 7 | 7 | 4 | 5 | 0 | 0 |
| LOF 1.5 | 16 | 13 | 20 | 11 | 8 | 0 | 0 |

(Isolation Forest·LOF는 서버 최신 코드 기준입니다. 아래 "화면에서 다르게 보일 수 있는 것" 참고.)

### 마할라노비스 (변수 조합 기준 — 변수별 표에는 값이 없고 한 번만 표시)

| 선택지 | D² 임계 (자유도 7) | 이상치 행 | 엑셀 행 |
|---|---|---|---|
| χ² 97.5% (표준) | 16.01 | 8 | 11, 26, 51, 76, 101, 151, 201, 251 |
| χ² 99% | 18.48 | 8 | 위와 같음 |
| χ² 99.9% | 24.32 | 8 | 위와 같음 |

→ **단변량 기법은 151·201·251행(조합 이상)을 거의 못 잡고, 마할라노비스만 8행을 전부 잡습니다.**
(IQR이 151행을 영어에서, 251행을 과학에서 잡는 정도입니다.)

## 화면에서 확인할 것

1. **1단계**: 파일이 한 건으로 반입되고 열이 9/9로 보이는지.
2. **2단계 진단 표**: `student_id`와 `passed`가 표에 없고, 7개 변수만 나오는지.
3. **IQR / Z-score / 수정 Z / Grubbs**: 위 표의 건수와 같은지. 결과 패널에 하한·상한이 보이는지(Grubbs는 서버 최신 코드에서는 "경계 없음").
4. **마할라노비스**:
   - 선택지가 `χ² 97.5% · D² > 16.01 (표준)` 등으로 보이는지(자유도 7).
   - 변수별 이상치 칸이 `-`이고, 표 아래 안내에 "변수 조합(행) 기준 … 이상치 8행"이 한 번 나오는지.
   - 이상치 정제에서 **윈저라이징·로그 변환이 비활성**이고 "Drop만 가능"으로 보이는지.
5. **Isolation Forest / LOF**: `satisfaction`, `grade`가 이산형이라 판정이 불안정할 수 있다는 안내가 나오는지.

## 화면에서 다르게 보일 수 있는 것 (테스트 서버가 이전 빌드)

현재 배포된 테스트 서버는 Isolation Forest·LOF의 임계값 처리가 **서버 최신 코드와 다릅니다.**

| 항목 | 테스트 서버(현재) | 서버 최신 코드 |
|---|---|---|
| Isolation Forest 임계값 | 0.55·0.60·0.65 모두 **결과가 같음** | 임계값에 따라 달라짐 (위 표) |
| Isolation Forest, `grade` | **300건 전부** 이상치 | 0건 |
| LOF 임계값 | 1.3·1.5·1.8이 같은 결과 | 임계값에 따라 달라짐 |

그래서 Isolation Forest·LOF 칸이 위 표와 다르게 나오는 것은 화면 문제가 아니라 서버 배포 전 상태입니다.
서버 최신 코드(PR #29)를 배포한 뒤에 다시 확인하면 위 표와 맞아야 합니다.
